# 49. Usability against Nielsen's ten heuristics (asked 2026-11-26)

*Asked 2026-11-26: "let's also go through using Nielsen Norman heuristics and look for
inconsistencies and other usability issues", run by Antigravity. It walked the web desk at
1440×900 and 1280×800, the phone layout at 390×844 and 412×915 and the phone remote in
Playwright with WebGPU on the owner's Mac, and read the Mac app's code (Electron was not
installed in its worktree, so 49k is from the code alone). 67 findings, scored on Nielsen's
severity scale (4 can wreck a show, 3 major, 2 minor, 1 cosmetic), grouped here into twelve
items ranked by what they risk at a gig. The screenshots and the full write-up of each finding
are in the owner's project files (`ux-review-2026-11-26/`); the ids below (H4-01: heuristic 4,
finding 1) are that review's. Six of the claims were checked against main at f3414ff before
they were written in: all six held.*

Already decided by the owner, so not reopened here: no Close-up button (Macro Zoom is the way
in), one kind of control per desk panel, no Send to wall on the plate bar, Source None when
the web app opens. A fix to any item ships its phone version in the same PR, like every other
item, and 49d continues §35's "one name for one thing".
