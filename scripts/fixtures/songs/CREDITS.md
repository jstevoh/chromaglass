# Songs for `npm run songends`

Recordings of real songs, for measuring where one song ends and the next begins
(PLAN.md 14z). Each is re-encoded to mono Opus at 24 kbit/s (changed from the
original files) to keep the repository small; they are test inputs, not shipped
with the app.
